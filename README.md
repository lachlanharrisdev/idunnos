# iDunnOS

iDunnOS is a security focused toy operating system built from scratch primarily as a learning exercise for C and x86 assembly. 

> **NOTICE**: in it's current state, the repo is heavily a WIP and instability is expected. It is HIGHLY recommended and to an extent required that any code within this repository should be executed within or as a virtual machine
