# About `docs/`

This folder contains documentation meant primarily for personal reference. It includes key notes about the BIOS and interaction between the software and the "hardware", and notes from tutorials or online resources. 

Contrary to other repositories, `docs` should not be relied upon for understanding how this repository functions and/or how to use or contribute to this codebase. It is rather supplementary information written without clear style guides or structure and may contain personal opinions or unverified information.
